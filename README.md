# Bilingual Portfolio (ES / EN)

This repo is ready for GitHub Pages + Jekyll (no plugins).  
**ES root** at `/` and **EN version** at `/en/`.

## Quick steps
1) Create a public repo named `Joselgc1.github.io`.
2) Upload these files: `git add . && git commit -m "bilingual init" && git push`.
3) In GitHub → Settings → Pages → Source: **Deploy from a branch** (main / root).
4) Your site: https://Joselgc1.github.io  (English at https://Joselgc1.github.io/en/)

## Customize
- Replace `assets/avatar.jpg` with your real photo (same filename).
- Upload `CV.pdf` to the repo root.
- Update links to your real repos in `projects` pages.
- If you add a custom domain, also add a `CNAME` file with your domain and enable HTTPS.
